# Ilanil Infotech - Official Website

> Full-Stack Software Engineering, High-Throughput Mobile APIs, Cloud Infrastructure & Scaled AI Deployments.

## 🚀 Overview

**Ilanil Infotech** provides end-to-end digital engineering and software services:
- **Full-Stack Web Development**: Modern responsive web applications built with React, Next.js, TypeScript, and Node.js.
- **Mobile Applications & Mobile APIs**: Fluid iOS & Android mobile apps with dedicated low-latency REST & GraphQL backends.
- **Cloud Infrastructure & Managed Hosting**: Docker containerization, automated CI/CD pipelines, AWS & Google Cloud environments, and 24/7 uptime monitoring.
- **Applied AI & Intelligent Automation**: Practical AI features, Large Language Model integrations (Gemini API), vector search (RAG), and smart automated workflows.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons
- **Backend / APIs**: Node.js, Express, RESTful & GraphQL architecture
- **Design System**: Plus Jakarta Sans, Dark Modern Palette (`#0b0f17`)

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/ilanil-infotech/ilanil.infotech.git

# Navigate to project directory
cd ilanil.infotech

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` or `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```
